# Weekly schedule maker and time budget

Free, single-file browser tool: enter your fixed blocks (sleep, work, commute, meals, activities) with their days and times, overnight blocks included. It draws the week, totals each block out of 168 hours, shows free hours and the longest free stretch of every day, and flags blocks that clash. Print and CSV export.

Live: https://ricco020.github.io/weekly-schedule-time-budget/

Printable weekly page for the rest of the week: [weekly planner](https://tidysheets.shop/p/weekly-planner-printable).

MIT licence. No network calls, the week stays in localStorage.
